# Ресурсы и зависимости

- Phaser 3 распространяется по лицензии MIT. [Текст лицензии](licenses/Phaser.md).
- Vite используется при сборке и распространяется по лицензии MIT. [Текст лицензии](licenses/Vite.md).
- Графика игрового мира и покадровая перерисовка героя создаются локально кодом в `src/art.js` для этого проекта. Исходный спрайт из пользовательского архива сохранён как материал для сравнения.
- Мелодия и игровые эффекты созданы для этого проекта и синтезируются кодом в `src/audio.js`. Сторонних аудиозаписей нет.
- Шрифт Press Start 2P распространяется по SIL Open Font License 1.1. [Текст лицензии](public/fonts/OFL-PressStart2P.txt).
