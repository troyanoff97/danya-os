# Danya OS

Пиксельный платформер на Phaser 3 с Arcade Physics.

## Запуск

Нужен Node.js 22.12+ или 20.19+.

```sh
npm ci
npm run dev
```

Сборка для размещения на статическом хостинге создаётся командой `npm run build` в каталоге `dist`.

## Управление

Стрелки или A/D перемещают героя. Space, ↑ или W запускают прыжок. **Enter — войти в портал.** Рядом с порталом также работает E. После падения герой возвращается на стартовый остров. Можно нажать на остров, портал или название приложения в каталоге. На телефоне есть отдельные сенсорные кнопки, в том числе для одновременного движения и прыжка.

## Приложения

В [src/worlds.js](src/worlds.js) задаются идентификаторы, названия, описания, адреса, цвета, значки, тематические анимации и доступность порталов. Заполните `url` у нужной записи полным HTTP(S) URL или путём к приложению на том же домене. При пустом `url` портал показывает временный экран, и кнопка «Открыть сразу» открывает его напрямую.

Для нового приложения добавьте запись с уникальным `id` в массив. Карта и каталог расширятся автоматически. Доступные темы `crown`, `rain`, `duck`, `bouquet`. Для закрытого портала установите `enabled: false`.

Музыка и эффекты синтезируются локально через Web Audio. Звук включён по умолчанию и начинает играть после первого взаимодействия со страницей. Настройка звука сохраняется в браузере.

## Контакты

Добавляйте публичные контакты в `src/contacts.js`. У каждой записи есть `title` (название), `value` (адрес или подпись), `href` (ссылка) и `icon` (символ). Для email используйте `mailto:` в `href`.
